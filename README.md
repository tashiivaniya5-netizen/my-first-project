## JARVIS desktop assistant

Run the Tkinter chat assistant with:

```bash
python3 jarvis_assistant.py
```

It can respond to greetings, identify itself, tell you the current time and
date, and show its available commands when you type `help`. Replies are handled
locally; no API key or network connection is needed.
